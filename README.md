# uTip

A modern, intuitive Tip & Bill Splitter built with Flutter.

uTip makes splitting restaurant bills and calculating tips effortless. Simply enter the total bill, select your preferred tip percentage, choose the group size, and get instant per-person totals in real time.

---

## Features

- **Real-Time Calculation:** Automatically calculates per-person share and total tip as values change.
- **Adjustable Tip Percentage:** Set custom tips between 10% and 50% using an intuitive slider or quick-select options.
- **Split Among Friends:** Easily adjust the number of people to divide the final bill fairly.
- **Clean UI:** Responsive layout built with Flutter's Material Design principles.

---

## How It Works

1. **Enter Total Bill:** Input the base bill amount (e.g., `$100`).
2. **Select Tip Rate:** Choose your tip percentage (from 10% to 50%).
3. **Set Group Size:** Adjust the total number of people splitting (e.g., `4`).
4. **Get the Split:** View the exact amount each person owes, including their share of the tip.
